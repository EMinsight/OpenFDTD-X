記録日: 2026-07-16。対象: `src/acoustics/` 音響コア +
`tests/acoustics/` 全テスト。
環境: Linux (Ubuntu 24.04), GCC 13.3.0, `g++ -std=c++14 -O2`

## 1. Schroeder 減衰カーブ + 回帰 (test_schroeder — 125 checks PASS)

理想指数減衰 `x(t) = e^(−6.91 t/RT)` の減衰カーブ傾きは厳密に
−60/RT [dB/s]。許容: 傾き ±1%、R² > 0.999。

| ケース | 実測傾き [dB/s] | 期待値 | 誤差 | R² |
|---|---|---|---|---|
| RT=0.5 s (補正なし) | −120.0390 | −120.0 | **0.032%** | **1.000000** |
| RT=1.0 s (補正なし) | −60.0195 | −60.0 | 0.032% | 1.000000 |
| RT=2.0 s (補正なし) | −30.0097 | −30.0 | 0.032% | 1.000000 |
| RT=1.0 s (Chu 補正あり) | −60.0195 | −60.0 | 0.033% | 1.000000 |

その他: 回帰区間が確保できない場合 (−200 dB まで届かない短い信号) の

## 9. 帯域フィルタの数値精度 (test_bandfilter — 563 checks PASS)

追記日: 2026-07-27 (負債 #7 の解消)。フェーズ1 時点では帯域フィルタの
検証が fs = 48 kHz のみだったため、fc/fs が小さい条件 (63 Hz @ 96 kHz →
fc/fs = 6.6e-4) で双一次変換の係数が悪条件にならないかが未検証だった。

検証方法は**厳密解との直接比較**。`BandFilter` はプリワーピング
W = tan(π f / fs) → 2次バターワース低域原型 → 低域帯域通過変換 →
双一次変換 → 中心で利得 1 に正規化、という手順で設計される。双一次変換は
W 平面と z 平面を 1 対 1 に写すので、離散フィルタの振幅特性は

  Ω(f) = (W² − W0²)/(B·W),  W0 = √(W1·W2),  B = W2 − W1
  |H(f)| = 1 / √(1 + Ω⁴)

と厳密に一致する。テストは正弦波応答の定常部を最小二乗フィット
(y ≈ a·cos ωn + b·sin ωn) して振幅を測り、この解析解と比較する
(ピーク値法と違いサンプリング位相誤差が入らない)。

| 帯域 | fs | 通過帯域 (fc) | エッジ | ±1 oct | ±2 oct | 解析解との相対誤差 |
|---|---|---|---|---|---|---|
| 63 Hz oct | 48 kHz | 0.999999851 | −3.0103 dB | −13.274 dB | −28.99 dB | 3.2e-7 |
| 63 Hz oct | **96 kHz** | 1.000003693 | −3.0103 dB | −13.274 dB | −28.99 dB | **3.7e-6** |
| 125 Hz oct | 96 kHz | 1.000000171 | −3.0103 dB | −13.274 dB | −28.99 dB | 5.4e-7 |
| 250 Hz oct | 96 kHz | 1.000000010 | −3.0103 dB | −13.274 dB | −28.99 dB | 6.4e-9 |
| 100 Hz 1/3oct | 96 kHz | 1.000003617 | −3.0103 dB | −32.46 dB | −48.37 dB | 7.2e-7 |

**96 kHz で精度低下は無い**。最悪ケース (63 Hz @ 96 kHz) でも解析解との
相対誤差は 3.7e-6 で、許容値 1e-3 (≈0.0087 dB) に対し約 270 倍の余裕がある。
係数の悪条件も否定できる: インパルス応答は末尾で ≤1e-21·peak まで減衰し
(63 Hz @ 96 kHz では 4.4e-33·peak)、DC 入力の漏れは ≤1e-13、
0.45·fs での減衰は −145 dB。NaN / 発散は全ケースで発生しない。

統合パイプラインは**決定的な多重トーン RIR** (8 オクターブ中心周波数の
正弦波を同一の指数包絡で減衰させた和 — 乱数を使わないので単一実現の統計
ゆらぎが無い) で検証し、48 kHz / 96 kHz の両方で全 8 帯域の
EDT / T20 / T30 が RT に対して **−0.037% 〜 +0.049%** で一致した
(48 kHz と 96 kHz の T30 の相互差は 0.2% 以内)。

なお人工白色雑音 RIR を帯域分割した場合の T30 は単一実現の統計ゆらぎが
支配的で、63 Hz 帯では 8 シードの実測で 48 kHz が最大 ±11.8%、
96 kHz が最大 ±11.2% ばらつく。**fs に依存しない**ため、これは
フィルタ精度ではなく狭帯域推定の分散である (test_reverberation が
Compat6 の ±5% 検証を 1 k/2 k 帯に限っているのと同じ理由)。

## 12. フォルマント推定 F1/F2/F3 (test_formant — 72 checks PASS)

追記日: 2026-07-31 (負債 #14 のフォルマント推定の解消)。
`FormantEstimator` (LPC) の検証。手順: 反エイリアス FIR (ハミング窓
sinc、10·M+1 タップ) + 整数間引き M = round(fs/10 kHz) で内部 fs ≈
10 kHz (48 kHz → M=5 → 9.6 kHz)、LPC 次数 p = 2 + round(内部 fs/1000)
(9.6 kHz → **p=12**、上限 24)、プリエンファシス 0.97 + ハミング窓 →
自己相関 → Levinson-Durbin → Durand-Kerner 法 (自前実装、決定的初期値
(0.4+0.9i)^k、乱数不使用) で A(z) の根 → 上半平面の安定極から
F = arg(z)·fs/2π、B = −ln|z|·fs/π。候補は F ≥ 90 Hz・B ≤ 400 Hz に
限定し昇順に F1/F2/F3。推定は YIN の有声判定フレームのみ、代表値は
有効フレームの時間中央値。

**数値部品の単体検証**:

- Levinson-Durbin: AR(2) (φ1=0.75, φ2=−0.5) の理論自己相関
  (Yule-Walker の厳密解) から係数を **1e-6 以内** (実測は倍精度で
  ~1e-15) で回復。p=4 でも AR(2) 部分を回復し余剰係数 ≈ 0。
  r[0] ≤ 0 / 次数 0 / 配列長不足は false。
- Durand-Kerner: 実根 (z−1)(z−2)、複素共役根 z²+1、非モニック、
  5 次 (根 ±1, ±2, 3)、LPC 極と同形の共役対 (r=0.95, θ=0.3)、1 次、
  先頭 0 係数の除去を 1e-8〜1e-9 で確認。重根 (z−1)² は残差判定で
  収束扱い (±1e-3)。空・定数・全 0 係数は false。

**合成母音 (全極モデル = 2 次共振カスケード、インパルス列駆動、
決定論的) — 公称値 ±10% 判定**:

| ケース | 公称 F1/F2/F3 [Hz] | 実測 [Hz] | 誤差 |
|---|---|---|---|
| /a/ 相当 (F0=120, B=80/90/120) | 700 / 1200 / 2600 | **713.4 / 1191.8 / 2616.3** | +1.9% / −0.7% / +0.6% |
| /i/ 相当 (F0=100, B=80/100) | 300 / 2300 | **326.4 / 2303.2** | +8.8% / +0.1% |

内部 fs = 9600 Hz (M=5)、p=12 であることも同時に確認。F1 の正の偏りは
声門パルス列 (F0 高調波) の離散サンプリングによる既知の LPC バイアスで、
許容 ±10% 内。白色雑音 (無声、シード固定 LCG) では有声フレームが無く
F1/F2/F3 の代表値が理由付き invalid になること、フォルマントフレームの
中心時刻・有声判定が F0 軌跡と完全一致し無声フレームでは推定しないことを
確認。

## 13. 帯域内 INR / ISO 3382-2 の動的範囲要求 (test_inr — 65 checks PASS)

追記日: 2026-08-07 (`RoomAcousticsTab` の INR 検査の実装)。
減衰時間 (EDT/T20/T30) が評価できるかは信号対雑音比で決まる。ISO 3382-2:2008
§5.3 / Table 1 は「評価区間の下端よりさらに 10 dB 下までノイズフロアが
下がっていること」を求めるので、必要な動的範囲は評価区間の深さ + 10 dB:

| 指標 | 評価区間 | 必要 INR |
|---|---|---|
| EDT |  0 〜 −10 dB | **20 dB** |
| T20 | −5 〜 −25 dB | **35 dB** |
| T30 | −5 〜 −35 dB | **45 dB** |

`requiredInrDb()` / `inrSufficient()` (`AcousticMetrics.h`) がこの表そのもの。
INR は帯域信号のピークと末尾区間ノイズフロアの差 (ISO 18233:2006 §3.6) で、
`RirAnalyzer` が **帯域ごとに** `BandMetricsResult::inrDb` へ入れる。
広帯域の `preprocess.dynamicRangeDb` とは別物である点がこの機能の理由で、
実測でも 1 dB を超えて食い違うことを検証している (下表の最終行)。

**合成 RIR (RT60 = 1.2 s、ノイズフロアはテスト側が指定した値) — 実測値**:

| ノイズフロア | 125 Hz | 250 Hz | 500 Hz | 1k | 2k | 4k |
|---|---|---|---|---|---|---|
| −70 dBFS | 64.4 | 66.8 | 67.3 | 67.5 | 68.5 | 70.5 |
| −30 dBFS | 24.4 | 26.5 | 27.2 | 27.4 | 28.8 | 30.5 |

(単位 dB。低域ほど INR が小さいのは、帯域フィルタ後のピークが下がるため。
ノイズを 40 dB 積むと全帯域で INR がちょうど 40 dB 下がる。)

**判定の整合 (この検証の本題)**:

- INR が要求値を下回る帯域で減衰時間が `valid` になることは**無い**
  (ノイズフロア −70 / −45 / −28 dBFS の 3 条件 × 6 帯域で確認)。
  これが破れると画面の「評価できない理由」が嘘になる。
- ノイズフロア −25 dBFS (最小帯域 INR 21.3 dB) では有効な T30 が 0 帯域。
- INR = peak − noiseFloor の恒等式、境界値 (45.0 は可 / 44.9 は不可) も確認。

許容誤差はいずれも定義式なので 1e-9 (恒等式) / 完全一致 (判定) で判定する。

## 14. ESS (指数掃引正弦波) の逆畳み込み (test_sweep — 47 checks PASS)

追記日: 2026-08-08 (`RoomAcousticsTab` の ESS 逆畳み込み / 高調波分離の実装)。
出典: A. Farina, "Simultaneous Measurement of Impulse Response and Distortion
with a Swept-Sine Technique", AES 108th Convention, Preprint 5093 (2000)。

実測の現場にあるのはインパルス応答ではなく **掃引を再生した録音** である。
逆フィルタで畳み込むと線形 IR が得られ、非線形歪みは線形応答より **前** の
時刻へ分離して現れる。

**掃引の瞬時周波数** f(t) = f1·(f2/f1)^{t/T} — ゼロ交差の数え上げで検証。
比べる相手は瞬時値ではなく **窓平均**
(1/w)·∫ f1·r^{s/T} ds = f1·T/(w·L)·(r^{(t+w)/T} − r^{t/T}) とし、
1 交差 = 1/(2w) Hz の量子化を許容幅にする (窓 0.05 s → ±20 Hz)。
実測 (f1=100 Hz, f2=8 kHz, T=1 s): t=0.2 s で 260.0 / 268.6 Hz、
t=0.5 s で 1000.0 / 1000.0 Hz、t=0.8 s で 3720.0 / 3723.2 Hz。

**逆フィルタの正規化**: 掃引 ⊛ 逆フィルタ = 振幅 **1.000000** の単一
インパルス (ピーク位置は `linearIndex` ちょうど)。実装はスカラーを解析的に
書き下さず、実際に畳み込んでピークで割ることで離散化と厳密に整合させている。

**復元されるのは帯域制限 IR であること (重要)**: 100 Hz〜8 kHz の掃引では
デルタは復元できない。核は非因果的で、ピークの前後 ±7.7 / ±17.7 / ±30 ms に
−14.9 / −22.4 / −26.8 dB のリンギングを持つ (下端 100 Hz の周期 10 ms に
対応)。検証はこの事実を固定したうえで、**線形時不変性**で判定する:

| 判定 | 実測 |
|---|---|
| 核のピーク | 1.0000 |
| 核の 5 ms 以遠のリンギング | 0.1794 (−14.9 dB) |
| 復元結果 vs h ⊛ 核 (±83 ms の最大差) | **3.33e-16** |

既知の IR (直接音 1.0 / 10 ms に −0.5 / 25 ms に +0.25) を掃引に畳み込んだ
録音から、タップの位置・符号が復元されること (実測 0.9991 / −0.4770 /
0.2839 — 公称からのずれは帯域制限のリンギングの重なりによる) と、
直接音が全体のピークで位置が 0 (時間原点がずれない) ことも確認する。

**高調波の分離**: N 次高調波は Δt_N = T·ln(N)/ln(f2/f1) だけ前に出る
(閉形式と 1e-12 で一致)。y = x + 0.2·x² の 2 次歪みを入れた系
(f1=100 Hz, f2=8 kHz, T=2 s, フェード 20/60 ms) で:

| 次数 | 前方位置 (実測 / 閉形式) | レベル |
|---|---|---|
| 2 | 0.3164 s / 0.3164 s | −27.5 dBc |
| 3 | (歪み無し — 窓はリンギングを拾う) | −76.2 dBc |
| 4 | 同上 | −106.4 dBc |

THD = 4.97 %。歪みの無い線形系では 2 次の窓が −51.7 dBc まで下がり、
歪みのある系 (−27.5 dBc) と **24 dB** の差がつく (判定は 15 dB 以上)。
掃引を長くしフェードを付けると次数間の間隔が広がり端の不連続が減るので、
この差は大きくなる (T=1 s フェード無しでは 14 dB)。

**不正入力**: 空の録音 / f2 ≤ f1 / f2 ≥ fs/2 / T ≤ 0 / 全 0 の録音は
いずれもエラーを返す (「それらしい IR」を作らない)。

## 15. ラインアレイ / サブアレイの指向性合成 (test_array — 59 checks PASS)

追記日: 2026-08-11 (`AcousticSourceTab` アレイページの実計算化)。
出典は古典的な配列理論 (一様直線アレイの 3 dB 幅・第一サイドローブ・
グレーティングローブ条件) と、エンドファイア / カージオイドサブの初等的な
2 素子和。外部ソルバーは使わない — 素子位置と遅延が決まれば遠方界は和で書ける。

**一様直線アレイ (ブロードサイド)**: 素子間隔 d = λ/2 で、3 dB 幅は
0.886·λ/(N·d) [rad] に収束する。

| N | 実測 3 dB 幅 | 0.886·λ/(N·d) | 第一サイドローブ |
|---|---|---|---|
| 8  | 12.78° | 12.69° | −12.80 dB |
| 16 | 6.348° | 6.346° | −13.15 dB |
| 32 | (0.1 % 一致) | — | −13.26 dB (教科書値と ±0.2 dB) |

N を増やすほど式に寄る (判定の許容幅も N=8 で 15 %、N=32 で 1 % と絞ってある)。

**ステアリング**: 遅延だけでビームが指定角へ向くこと (10° / 20° / −15° を
±0.1° で再現)。実現できない負の遅延を作らないよう、最小遅延が 0 になるよう
平行移動していることも確認する。

**グレーティングローブ**: 出現周波数 f = c/(d·(1+|sinθ_s|))。d = 0.35 m /
ブロードサイドで 980 Hz。ちょうどこの周波数で ±90° の応答が主極大と同じ
0 dB になり (1e-6 以内)、半分の周波数では両端とも −10 dB 以下になる。
θ_s = 30° で出現周波数が 2/3 倍になることも確認する。

**splay (J カーブ) のカバー範囲**: **主ローブの −3 dB 幅はカバー範囲ではない**。
12 素子 / 0.35 m / splay 0…14° の J カーブは、1 kHz で主ローブこそ 5.4° と
細いままだが、−6 dB が及ぶ角度は −3.6°〜+64.0° に広がる (ストレートは
−3.6°〜+3.6°)。判定は −6 dB 範囲が 3 倍以上に広がることと、広がりが
下向き (splay の向き) であることを見る。

**カージオイドサブ**: 逆相 + 遅延 τ = d/c で、後方は**全周波数で**打ち消され
(30 / 50 / 80 / 120 Hz いずれも −100 dB 以下)、前方は d = λ/4 の周波数で
+6.02 dB (2 倍) になる。遅延が半分だと打ち消せない (−10 dB より上)。
同相・遅延 0 では前後比 0 dB で指向性が生まれないことも確認する。

**不正入力**: 素子 0 個 / 間隔 0 / 周波数 0 / 音速 0 / 空のパターンは
いずれも valid = false を返す (「それらしいビーム」を作らない)。

## 16. 可聴化用の帯域制限クリック (test_testsignal — 41 checks PASS)

`src/acoustics/core/TestSignal.{h,cpp}` — 室内音響タブ「可聴化 → ソース音源 →
クリック」が生成するドライ音源。無響の音声・音楽素材は第三者の録音のため
同梱できないが、クリックはこちらで作れる。

**なぜデルタではないか**: 1 サンプルだけ 1 を立てた信号はナイキストまで
一様なスペクトルを持ち、再生系の帯域外成分がそのまま折り返し歪みになる。
窓関数法 (Hann 窓 × 理想帯域通過のインパルス応答) で帯域を切ってから使う。

期待値は窓関数法の教科書的性質から独立に決め、テスト側で FFT を掛けて実測する
(fs 48 kHz / 100 Hz–8 kHz / 窓長 20 ms = 961 タップ):

| 性質 | 期待 | 実測 |
|---|---|---|
| 通過域リップル | Hann 窓なら ±0.1 dB 級 | **0.015 dB** |
| 阻止域 | Hann の最大サイドローブ −31 dB + ロールオフ | **−55.3 dB** |
| 遷移帯域幅 | Δf ∝ 1/N (窓長 2 倍で半分) | 75.7 Hz → 38.3 Hz (**0.506 倍**) |
| 直流成分 | Σh = 0 | 相対 **< 1e-12** |
| 線形位相 | 中心について対称 | 差 < 1e-15·振幅 |
| ピーク | 中央サンプル・指定振幅ちょうど | 一致 (1e-15) |

**直流除去**: 窓長が有限なので、下側遮断 fl が遷移帯域幅より狭いと直流が
残る (既定の fl = 20 Hz はまさにその状態)。窓そのものの形 k·w[n] を引くと
Σh = 0 を厳密に満たしたまま対称性と両端の 0 が保たれ、引いた分のスペクトルは
直流まわり ±Δf に集中するので通過域は動かない。fl = 20 Hz でも Σh = 0 が
成り立つことを検証に入れてある。

**通過域の一様性**: 500 Hz と 5 kHz の正弦波を直接畳み込み、利得の差が
0.2 dB 以内であることを確かめる (スペクトルの平坦さを時間領域からも見る)。

**不正入力**: fh ≤ fl / fh ≥ fs/2 / fs = 0 / 窓長 0 / 振幅 0 または 1 超 /
タップ数 9 未満はいずれも valid = false で空バッファを返す (無音を
「生成できた」と装わない)。
