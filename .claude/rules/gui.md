# GUI 層 (C++17 + Qt6) の規則

- **Qt API は 6.4.2 で使えるものに限る** (CI Linux の apt Qt が下限。
  Windows CI は 6.8 だが、6.5+ の API を使うと Linux ジョブで落ちる)。
- 重い処理 (秒単位の分析・変換) を GUI スレッドで同期実行しない。
  既知の負債: VocalAnalyzer の YIN が同期実行で ~2 秒/10 秒クリップ。
  新規機能で同じパターンを増やさない (QtConcurrent 等を検討)。
- タブ間で共有できるヘルパー (品質バッジ、CSV/JSON 保存、波形
  エンベロープ等) は既存の `RirAnalysisTab` からコピーせず、
  共有ヘッダへ抽出してから使う。
- プロット/テーブルは既存部品 (`MiniPlot`, `SectionBox`) を使う。
  外部プロットライブラリを追加しない。
- 入力バリデーション: 不正値を検出したら「警告表示 + モデルへ
  書き込まない」だけでは不十分 — UI とモデル/保存内容が乖離しない
  ように、有効フラグを落とすか実行/保存をブロックする。
- 実行結果の表示は「その実行が生成したもの」だけに限定する
  (作業ディレクトリの残存ファイルを後続の無関係な実行で
  再表示しない — 実行種別のチェックか実行前クリーンアップを入れる)。
- 文字列は直接書かず `I18n` に日英ペアで追加する。
- **UI 文字列に markdown を書かない。** `QLabel` の既定 (`Qt::AutoText`) は
  HTML は検出するが markdown は解釈しないので、`**強調**` と書くと
  アスタリスクがそのまま画面に出る。強調は日本語なら `「」`、英語なら
  文の組み立てで表す。RichText へ倒す案は不可 — UI 文字列には
  `<kernel>.log` のように山括弧を含むものがあり、タグとして食われる。
  selftest の `ui-markdown` が `**` の混入を検出する。
